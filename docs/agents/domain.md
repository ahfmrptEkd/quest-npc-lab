# Domain docs

## Layout and reading

This is a single-context repository.

Before exploring, read root `CONTEXT.md` if present and relevant ADRs under
`docs/adr/`.

If these documents are absent, proceed silently. Do not create empty
placeholders. `/domain-modeling` creates them when terminology or
architectural decisions need recording.

## Vocabulary and decisions

Use the vocabulary defined in `CONTEXT.md`. If a needed concept is missing,
reconsider the term or note the gap for domain modeling.

Surface conflicts with an existing ADR explicitly rather than silently
overriding it.
