# Quest NPC Lab

한국어 퀘스트 NPC의 행동 선택을 **프롬프트 개선 → LoRA SFT → GRPO**로 비교하는 연구 포트폴리오 프로젝트.

> **현재 상태: 설계 승인 완료, 구현 전.** 데이터 구축·학습·평가·공개 데모는 아직 실행하지 않았으며, 패키지와 CLI는 구현 전입니다. 아래 내용은 계획이지 완료된 실험 결과가 아닙니다.

## 실험 범위

- 길드 접수원 하나가 플레이어 요청과 신뢰할 서버 상태를 함께 해석합니다.
- 여섯 행동과 JSON 출력 계약을 평가하고, 모델의 원래 선택과 서버의 실행 승인을 구분합니다.
- 승인된 합성 데이터 300건을 학습 180 / 검증 60 / 최종 평가 60으로 분리합니다.
- 네 비교군의 최종 응답 240개와 별도 대사 품질 표본 48개를 검토합니다.
- 단일 seed의 탐색적 실험으로, 개선·동률·퇴행을 모두 보고할 계획입니다.
